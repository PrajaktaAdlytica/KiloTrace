# KiloTrace

Premium SaaS website and brand system for KiloTrace, a Poland/EU-based material loss intelligence platform for manufacturers.

## Website

Static site files are in `outputs/kilotrace-site/`.

- `index.html` - homepage
- `track.html` - KiloTrace Track product page
- `root.html` - KiloTrace Root product page
- `cost.html` - KiloTrace Cost product page
- `signin.html` - sign-in page
- `request-demo.html` - demo request page
- `demo.html` - contact page
